# source-command-review-memory

When the user invokes the migrated `review_memory` command, load `.claude/commands/review_memory.md` and follow it under root `AGENTS.md`.

The active tool's supported memory store is authoritative; do not assume every agent shares a vendor-specific directory. Ask for a location if it is not provided. Preserve privacy and obtain explicit keep/update/delete choices before changing memory.
