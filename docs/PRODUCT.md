# Product Intent

This repository is the LuckyStack framework and a reference application used to develop and evaluate it. The reference app is not a product for end users and should not become a consumer app's assumed domain model.

## Who it serves

- Framework contributors need a real application surface to validate reusable contracts, not just isolated library tests.
- Developers evaluating LuckyStack need to assess the model before adopting it in their own product.

The separate Workspace handoff material is historical/prototype context, not an active LuckyStack feature commitment.

Page-specific purpose belongs beside each page as a short intent annotation. Consumers maintain their own product intent; do not copy this reference-app identity into a new application.
