# @luckystack/server

Bootstrap for LuckyStack HTTP and Socket.io. Install with `npm install @luckystack/server socket.io`; add feature packages such as `@luckystack/api` or `@luckystack/sync` only when used (optional peers in `package.json`). Prefer `bootstrapLuckyStack` for ordinary boot: register project configuration, bootstrap with your application's static-file handlers, run `verifyBootstrap` after registration, then listen. `createLuckyStackServer` requires ownership of registration and readiness checks. See `src/bootstrap.ts` and `src/verifyBootstrap.ts` for current requirements.

Server is the common security perimeter: preserve origin, CSRF, socket authorization and route-specific checks when adding custom routes. Webhook origin exemptions require independent caller authentication. Test-only reset must remain unreachable in production. See [design context](./AGENTS.md), [security rationale](./docs/security-defaults.md), and [runtime maps](./docs/runtime-maps.md). Runtime arguments and options are defined by `src/argv.ts` and `src/types.ts`.
