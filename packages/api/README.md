# @luckystack/api

Type-safe API handlers for LuckyStack's socket-first transport with HTTP fallback. Install with `npm install @luckystack/api socket.io`; add optional `@prisma/client` for Prisma-backed routes (see `package.json`). The server package normally wires the handlers; route discovery and typed maps are generated by devkit.

Keep the same authorization and validation boundary on both transports. A declared HTTP method cannot protect a WebSocket route. When route inference fails, regenerate artifacts and fix the source type instead of casting. See [design context](./AGENTS.md), [auth rationale](./docs/auth-flow.md) and [generated types](./docs/generated-types.md). For signatures and route declarations consult `src/` and the generated map.
