# Redis adapter

Redis provides cross-instance socket delivery and shared state. A local socket room enumeration cannot see peers connected to another process; adapter-aware enumeration is necessary for fanout. See `../src/socketRedisAdapter.ts` and `../../sync/src/_shared/clientFanout.ts`.

**The adapter key is the cluster boundary.** The key names the adapter's pub/sub channels, so every instance on the same key and the same Redis server is one Socket.io cluster: broadcasts reach all of them, and a cross-instance room lookup waits for each of them to answer. Upstream's fixed default key turned two deployments that merely share a Redis server (a dev laptop tunnelled into the staging Redis, staging and production on one managed instance) into one cluster — staging's broadcasts reached the developer's sockets and staging's lookups hung on a sleeping laptop. The framework therefore derives the key from the project name plus the deploy-topology environment key, which keeps the instances of one environment together and separates environments without a setting; a consumer that wires its own adapter or probe should reuse the exported resolver rather than copy the string. The adapter key isolates the socket cluster, not the data: sessions, rate limits and other Redis keys are namespaced by project name only, so two environments sharing a Redis server and a project name still share a session store. ADR 0063 records why this mattered for sync delivery. Source: `../src/socketRedisAdapter.ts`.

**Upgrade note.** When a release changes the derived key, old-key and new-key instances do not see each other until a rolling deploy completes. On a single replica nothing is observable; on several, cross-instance fan-out is split for the duration of the rollout.

Consumer-registered Redis clients own their connection lifecycle, including credential rotation; framework-owned defaults may be refreshed automatically without replacing consumer infrastructure. Preserve Redis key namespace boundaries when customizing key formatting so enumeration and tenant isolation remain correct. Source: `../src/redis.ts`, `../src/redisKeyFormatter.ts`.
