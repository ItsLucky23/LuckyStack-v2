Log: de scaffold-stap eindigde in **0,63 seconde, met exit 0 en zonder één regel output**, waarna de directory-check terecht rood ging. Oorzaak zit in de CLI zelf: `isCliEntry()` vergeleek `process.argv[1]` met `__filename` als kale strings. npm installeert een bin op macOS/Linux als **symlink**; node rapporteert dan de symlink in `argv[1]` maar resolvet `import.meta.url` naar het doel, dus de check is daar permanent false en `main()` wordt nooit aangeroepen. Windows heeft die symlink niet (npm schrijft een `.cmd`-shim met het echte pad) — vandaar lokaal altijd groen en op Linux altijd stuk. Mechanisme lokaal gereproduceerd via een directory-junction. Dit is geen CI-bug maar een **shipping-bug**: `npx create-luckystack-app` deed op elke macOS/Linux-machine niets, stil en met exit 0. Beide kanten worden nu realpath-resolved; `cliEntry.test.ts` pint het symlink-geval vast (skipt waar de OS geen symlink toestaat).

**3. PR #9 kreeg geen enkele CI-check.** Verklaring gevonden: `pull_request` draait tegen `refs/pull/N/merge`, en die merge-ref kan GitHub niet bouwen zolang de PR conflicteert (`mergeable: CONFLICTING`). Er was dus niets mis met de trigger — de merge hierboven lost het op.
