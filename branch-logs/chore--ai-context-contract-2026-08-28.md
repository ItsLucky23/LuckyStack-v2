## 2026-08-28 15:45 — v0.9.0 release voorbereid: pipeline-gate volledig groen

**User prompt (summary):** Dit nu releasen via de GitHub-pipeline. Draai alle tests, zorg dat alle scripts alleen groen teruggeven, en publiceer.

**What I did:** eerst de gate lokaal gespiegeld die `publish.yml` daadwerkelijk draait, want die is breder dan wat ik voor de feature-grens gebruikte. Dat legde twee echte blockers bloot die de pipeline rood zouden hebben gemaakt:

1. **`npm run lint:packages` faalde op mijn eigen mcp-code** — `unicorn/no-array-sort` op `[...seen].sort()` in de nieuwe `reverseClosure`, en een `@typescript-eslint/no-unnecessary-condition` op `graph.symbolBlastRadius ?? {}` (het `??` is overbodig geworden nu `Graph` het veld gegarandeerd levert). `npm run lint` dekt alleen `src/`, `server/`, `shared/` en `config.ts` — `packages/` niet. Beide gefixt.
2. **`packages/test-runner/src/runAllTests.test.ts` was flaky** en zou op drie plekken kunnen falen (CI node 20, CI node 22, publish). Diagnose: het bestand mockt alles behálve `@luckystack/login`, dat `buildAuthHeaders` via een runtime-`await import(...)` binnenhaalt om de CSRF-token op te halen. Onder load overschreed die echte package-load de 5s-timeout; de afgebroken test hield zijn promise-keten wél draaiend, en die riep de layer-mocks aan ná de `clearAllMocks` van de vólgende test. Daardoor las een test die zelf niets fout deed de Cookie-header van zijn voorganger uit `mock.calls[0]` — precies twee failures, en de gerapporteerde was niet de kapotte. Bevestiging zat in de timings, niet in de assertie: na het mocken zakte de `tests`-tijd van dat bestand van 366ms naar 35ms. Vastgelegd als lesson 0019.

Daarnaast een derde vondst tijdens het bumpen zelf: **`npm run bump minor -- --dry-run` voerde een échte bump uit**. `dry-run` is een geldige npm-config-key, dus npm consumeert de flag en exporteert hem als `npm_config_dry_run` in plaats van hem door te geven — ondanks de `--`. De packages stonden daardoor even op 0.10.0. Teruggezet naar 0.9.0 met `setPackageVersions.mjs` en `bumpVersion.mjs` leest nu beide bronnen, zodat de gedocumenteerde aanroep niet stilzwijgend kan schrijven.
