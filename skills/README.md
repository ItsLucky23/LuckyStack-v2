# LuckyStack skills

Skills capture judgment and verification for a bounded task; they should not become copied API documentation. Tool discovery/loading is harness-specific—placing a file here does not prove every assistant will load it automatically.

Keep shared authority in root `AGENTS.md`, concrete contracts in source/types and workflow rationale beside the relevant skill. Do not maintain a second skill catalogue in prose; inspect/query the skill files when choosing one.

Custom skills are framework-owned. The official area is reserved for externally maintained skills and must not be silently rewritten as framework guidance.
